# Motor de automatización

Este módulo contiene la base para conectores por plataforma (API o scraping vía Playwright/Selenium).

## Flujo sugerido
1. Buscar vacantes por filtros y palabras clave.
2. Calcular score de compatibilidad con perfil.
3. Auto completar formularios y adjuntar CV.
4. Registrar estado en backend.

> Nota: integraciones reales dependen de TOS y APIs de cada plataforma.
